Les données que nous traitons

  • Ce que vous nous transmettez. Si vous nous écrivez ou nous appelez (e-mail, téléphone, messagerie), nous traitons les informations que vous nous donnez : identité, coordonnées, message et éléments de votre projet d'achat.
  • Données techniques. Comme tout serveur web, l'hébergeur enregistre dans ses journaux l'adresse IP, la date et les pages demandées, pour faire fonctionner et sécuriser le site.
  • Mesure d'audience. Aucune : ce site n'installe aucun outil de mesure d'audience ni de publicité.

Pourquoi nous les traitons

  • répondre à votre demande et, si vous le souhaitez, vous accompagner dans votre projet d'achat ;
  • faire fonctionner et sécuriser le site.

Nous traitons ces données parce que vous nous avez adressé une demande ou avec votre accord. La mesure d'audience n'est activée qu'avec votre consentement.

Transferts hors du Maroc

Selon l'emplacement des serveurs de l'hébergeur, des données peuvent être traitées hors du Maroc.

Si vous nous contactez par une application de messagerie, vos messages sont aussi traités par son fournisseur, selon ses propres conditions, et peuvent l'être hors du Maroc.
